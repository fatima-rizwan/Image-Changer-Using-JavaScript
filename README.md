# <img src="https://img.icons8.com/ios-filled/50/FFFFFF/image.png" width="32" height="32" alt="Image icon" /> Image Changer

**An interactive image changer application built using HTML5, CSS3, and JavaScript.**

A simple front-end project that allows users to change images dynamically through JavaScript functionality while exploring DOM manipulation and event handling.
